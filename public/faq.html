FAQ

Short answers to the questions that come up most often. Two longer notes are worth reading before the list if you are troubleshooting: how resolution and DPI relate to pixel size, and the Lab Notes, where several of the behaviours below are measured rather than asserted.

Are my images uploaded to a server?
No. Everything runs in your browser; images are never uploaded to any server and we keep no copies. Results disappear from memory when you close the page.
Do I need to sign up?
No. PicCalc is completely free — just open it and start. No registration or login needed.
Which image formats are supported?
Input supports PNG, JPG/JPEG, WebP, GIF, BMP, SVG, AVIF, ICO and HEIC/HEIF. Output depends on the tool: PNG keeps transparency, JPG/WebP are smaller, and the ICO tool writes a real multi-size .ico file.
Is there a usage limit?
There are no limits — use every tool as often as you like, with no daily cap.
Do you add watermarks?
No. No PicCalc tool adds a watermark.
What image sizes are supported?
We recommend under 5 MB per image with edges no longer than 3000 px. Larger images take longer locally and are more likely to hit browser memory limits.
Why do automatic tools struggle with some images?
All tools here run on deterministic browser algorithms — Canvas pixel operations, format decoding and file containers. Nothing is sent to a server, and no AI model or cloud service is involved, so results are predictable and repeatable.
Are results stored on your servers?
No. Results exist only in the memory of your current tab and vanish when you close it — download them promptly.
Does it work on mobile?
Yes. The layout adapts to mobile and your phone browser can upload gallery photos directly, though large images process noticeably slower than on a computer.
There are ads — do they affect anything?
The site is funded by Google AdSense advertising. Ads do not affect any tool's features or usage limits, nor the image processing results.
Why does a tool page show no controls or do nothing when I click?
Every editor is JavaScript. If scripting is disabled, or an extension blocks it, the control panel never initialises and the page shows a notice above the upload area explaining that. Enable JavaScript for the site and reload; the written documentation below the tool still reads either way.
Why is my large photo smaller after processing?
The editors fit the source onto a working canvas capped at 3000 px on the longest side, and report the reduction under the original preview. A 6000 px photo therefore comes out at 3000 px. The cap exists because the pixel loops run in the tab, and it applies before any filter, rotate or trim.
Why is the download a PNG when I uploaded a JPG?
Most editors write PNG because it is lossless and keeps transparency. Only Convert Format writes JPG, WebP or ICO. If the PNG is too heavy, run it through Compress Image, or convert it once at the end of the workflow rather than after every step.
Does processing remove EXIF metadata?
Yes, as a side effect. Each result is re-encoded from a canvas, and a canvas carries no EXIF block, so GPS coordinates, capture time and camera details are not present in the output. This is not a metadata editor: individual tags cannot be kept or edited.
Can I use the tools offline?
After a page has loaded, all processing is local and continues to work if the connection drops. There is no offline installation or service worker, though, so the page itself has to be fetched once each time you start a new session.
Can I process several images at once?
No. Each tool handles one image per pass, and Stitch and Images to PDF accept a set only to combine it into one output. Repeating the same settings on the next file is the batch workflow; the numbers are deterministic, so the same values give the same transformation.
Why did trimming or background cleanup fail on my image?
Those tools compare pixels against a reference colour within a tolerance. Gradients, drop shadows, uneven lighting and anti-aliased edges fall outside a single reference, so the scan either finds nothing to remove or stops early. Adjust the tolerance, pick the edge colour manually, or crop by hand instead.
Is there a file size limit?
No explicit byte limit, but there is a practical one. A file under about 5 MB and under 3000 px on the long side will process comfortably on a desktop browser; larger files take longer and are more likely to exhaust the tab's memory, especially on a phone.
