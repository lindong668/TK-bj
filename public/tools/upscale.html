How to upscale an image

  1. Upload the image you want enlarged
  2. Choose a scale factor (2×–4×)
  3. Click "Upscale" — large images take a few seconds
  4. Preview, then download

How it works

Ordinary enlargement uses nearest-neighbour or bilinear interpolation: nearest-neighbour simply copies adjacent pixels and produces visible jaggies and blockiness, while bilinear blends linearly and softens edges.

This tool uses Lanczos3: it takes the 6×6 block of 36 source pixels around each target pixel and averages them with a sinc window function. Weights decay with distance and include slight negative lobes, which strengthens edge contrast — so lines come out sharper.

One caveat: no interpolation algorithm can invent real detail. Upscaling makes an image look smoother and sharper, but it does not recover information lost at capture time.

FAQ about upscaling

Does upscaling make it sharper?

It will be sharper than plain stretching, but it cannot truly restore detail. Interpolation only smooths pixel transitions; it cannot generate information the original scene lost.

Why is 4× so slow?

Lanczos3 weighs 36 source pixels per output pixel, and 4× means 16 times as many pixels — a lot of computation. Use 2× for large images.

How is this different from AI super-resolution?

AI super-resolution uses neural networks to guess and fill in detail — more impressive, but it can invent unrealistic content. This tool is pure mathematical interpolation: faithful to the original and far more predictable.

What is the upscaling limit?

Maximum 4000 px per output side. Beyond that the factor is reduced automatically to avoid exhausting browser memory.
