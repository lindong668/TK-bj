How to resize an image

  1. Upload: Drop an image; its dimensions are shown as a reference.

  3. Enter the target size: Enter width or height and the other follows the original ratio automatically, or set it by hand.
  4. Process and download: Check the result size before downloading.

Tip: All processing happens in your browser: images are never uploaded to a server. Results live only on this page, so download them promptly.

How it works

Resizing means resampling the pixel grid. When shrinking, many source pixels merge into one and the browser averages them so edges stay smooth. When enlarging, colours must be invented for positions that did not exist before, inferred only from neighbouring pixels.

That is why shrinking is almost always safe while enlarging blurs: shrinking discards excess information, enlarging has to fabricate it. However good the interpolation (bilinear, bicubic), it can only smooth the transitions — it cannot recover real detail.

The other key point is aspect ratio. Changing width without height stretches the image. Keeping the ratio means multiplying both by the same factor.

FAQ about resizing

Why is it blurry after enlarging?
Enlarging interpolates new pixels and cannot add real detail — that is a physical limit. Keep enlargements modest (under 1.5×), or find a higher-resolution source.
Why did my image distort when I changed the width?
Because the height was not changed to match. Tick "keep aspect ratio" so height follows automatically.
Does enlarging after shrinking restore quality?
No. Shrinking already discarded pixels; enlarging only interpolates them back, and quality does not return. Keep the original.
What if a platform requires under 2 MB?
Dimension limits and file size limits are different things. Shrinking dimensions reduces size; if that is not enough, use the Compress tool to tune quality.
