How to make icons

  1. Upload a source image: Choose a square image as the icon base; 512 × 512 or larger is recommended.
  2. Choose output sizes: Tick the sizes you need to generate several at once.
  3. Optional — rounded corners: Rounds corners to match the platform; iOS is rounder.
  4. Generate and download: Download each size and drop it into your project.

Tip: All processing happens in your browser: images are never uploaded to a server. Results live only on this page, so download them promptly.

How it works

One icon needs different sizes in different places: 16 × 16 for a browser tab, 180 × 180 or larger for a phone home screen, and possibly 1024 × 1024 for an app store. Letting the system scale one large image down blurs the small sizes into mush; generating each size separately keeps it sharp everywhere.

Generation resamples the artwork to each target size (same principle as the Resize tool), applies a rounded clip path if requested, then encodes to the matching format.

Favicons are usually ICO or PNG. Modern browsers widely support PNG favicons, which are smaller; a true ICO is only needed for very old browsers. ICO's distinguishing feature is packing several sizes into one file.

FAQ about icon making

What if my source is not square?
It will be stretched. Crop it to 1:1 with the Resize tool first, then make the icon.
Should I use PNG or ICO?
PNG is enough for modern browsers, and it is smaller and sharper. ICO is only required when supporting very old browsers.
Why do small icons look mushy?
Shrinking a large image crams detail together. Keep the artwork simple and the outline clear, avoiding tiny text and busy textures.
How much padding should the icon have?
Leave 10%–15% padding all around. Many platforms add corners or shadows automatically, so edge-touching content easily gets clipped.
