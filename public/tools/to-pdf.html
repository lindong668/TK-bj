How to convert images to PDF

  1. Select several images at once (multi-select allowed)
  2. Use ↑ ↓ to set page order, ✕ to remove
  3. Choose a page size: A4 for printing, "Match image" for archiving
  4. Click "Generate PDF", check the size, then download

How it works

Images are embedded in a PDF as JPEG data streams. Each page holds an XObject image drawn onto the page via a coordinate matrix (the cm operator).

With A4 selected, the page is 595×842 points (210×297 mm); the image is scaled proportionally, centred and padded so nothing is distorted.

The generated PDF has a complete header, object table, cross-reference table and trailer, conforming to PDF 1.4 and openable in every major reader.

FAQ about image to PDF

Can the PDF be printed?

Yes. With A4 the page is a standard print size, the image is centred with margins, and you can print directly.

Why was my image scaled down?

To keep generation fast and files small, anything over 2000 px per page is scaled down proportionally. For printing, 2000 px is already plenty sharp.

Can text in the PDF be selected?

No. This tool embeds the whole image without OCR, so text is part of the picture and cannot be selected or searched.

Can I set a password or permissions?

Encryption is not supported in this version. Use dedicated PDF software if you need it.
