How to split a long image

  1. Upload a long image (chat screenshots, full-page captures, etc.)
  2. Choose a method: split into equal parts, or set a fixed height per slice
  3. Click "Split" and all slices are listed below
  4. Download a single slice, or use "Download all" to save them at once

How it works

When splitting by count, the total height is divided by the number of parts, and the last slice absorbs any remainder — so individual heights can differ by 1–2 px.

When splitting by fixed height, slices are cut from the top down, and any leftover shorter than one slice becomes its own slice — no content is lost.

Splitting simply copies pixels from vertical ranges of the original canvas, with no scaling or resampling, so every slice keeps the original sharpness.

FAQ about splitting

Does splitting reduce quality?

No. Splitting is pure pixel copying with no scaling or recompression, so each slice matches the corresponding region exactly.

Can I split horizontally?

This version supports vertical (height-based) splitting only, which covers most long-image needs. For horizontal, use the Crop tool first.

Will downloading all at once miss files?

Browsers throttle consecutive downloads, so the tool waits 350 ms between slices. If your browser asks whether to allow multiple downloads, choose Allow.

How many slices can I make?

Up to 20 by count. Splitting by height depends on the total height, so there is no real upper limit.
