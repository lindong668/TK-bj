How to use this tool

  1. Upload the image you want to frame.
  2. Set border width and padding (matte) in pixels; each side gets the same amount.
  3. Choose border and matte colours, corner radius, and whether to add a soft shadow.
  4. Preview the exact output size, then download the PNG.

Note: All processing happens in your browser: images are never uploaded. Download the result before closing the page.

How it works

The tool creates a new canvas whose size equals the source plus twice the border, padding and shadow margin. It paints the outer rounded rectangle in the border colour, an inner rounded rectangle in the matte colour, then clips and draws the original image in the centre.

Because the source is drawn at its native pixel size, there is no resampling and no quality loss. The shadow is a standard Canvas shadow on the outer shape, so corners and transparency behave predictably.

Common use cases

Frequently asked questions

Does adding a border reduce image quality?
No. The original is drawn at 1:1 pixel size onto a larger canvas; only new empty pixels are added.
Why is the output bigger than my image?
Border, padding and shadow margin are added on all four sides, so both dimensions grow by twice the total.
Can I keep transparent corners?
Yes — set the border colour to a transparent-friendly PNG workflow, or pick the Rounded Corners tool for a pure transparent mask.
Is the image uploaded?
No. All drawing happens in your browser on an off-screen canvas.
