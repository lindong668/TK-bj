How to compress an image

  1. Upload: Drop an image in and the page shows its original file size as a baseline.
  2. Set the quality: Drag the slider to set quality. 70–80 suits web images; drop to 60 when size matters more.
  3. Optional — cap the width: Enter a maximum width and wider images are scaled down proportionally — usually the most effective way to cut size.
  4. Compress and compare: The compressed size and saving are shown afterwards; download once the quality looks acceptable.

Tip: All processing happens in your browser: images are never uploaded to a server. Results live only on this page, so download them promptly.

How it works

Image compression comes in two flavours. Lossless compression simply re-describes the same pixels with a smarter encoding, trimming size but only modestly. Lossy compression discards visual information the eye barely notices, in exchange for a far bigger size cut. This tool uses the latter, controlled by the JPEG quality parameter.

The quality value controls how coarse the quantisation table is: the lower it goes, the more crudely colour and detail are quantised and the smaller the file — but blocking artefacts appear, most visibly around high-contrast edges such as text.

Capping the width is actually a more effective way to shrink a file. A 4000 px wide photo reduced to 1600 px has about one sixth as many pixels, and the size usually drops just as sharply — while looking virtually identical at that scale.

FAQ about image compression

Why did the file get bigger after compressing?
The original was already heavily compressed (a previously saved JPG, or an image sent through WeChat). Compressing again removes nothing, and re-encoding can even add a little size. Cap the width instead of pushing quality lower.
What quality should I use?
For web images 70–80 usually balances size and appearance. To hit a strict KB target, start at 75 and step down if needed, zooming in to check for blocking around text edges.
Does compression keep transparency?
Output is JPEG, which has no alpha channel, so transparent areas are filled with white or black. To keep transparency, use PNG and reduce size with the Resize tool instead.
Can lost quality be recovered?
No. What lossy compression discards is gone for good — keep your original.
