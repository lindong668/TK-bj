How to round corners

  1. Upload: Drop in an image. For avatars a square original gives the neatest result.
  2. Choose a shape: Rounded rectangle or circle; circle crops to a disc.
  3. Set the corner radius: Drag to set the radius; half the side length is a circle.
  4. Download as PNG: Choose PNG so the area outside the corners stays properly transparent.

Tip: All processing happens in your browser: images are never uploaded to a server. Results live only on this page, so download them promptly.

How it works

Rounded corners rely on a canvas clipping path: quadratic Bézier curves trace the four corners into a closed path, and the canvas draws only inside it. Pixels outside are never painted, so they stay transparent.

So the area outside the corners is transparent, not white. That transparency survives only if the output format has an alpha channel: PNG and WebP do, JPG does not — which is why the wrong choice turns those corners into black or white blocks.

A circular avatar simply swaps the clip path for an ellipse. If the source is not square, cropping to a circle yields an oval — square it up first.

FAQ about rounded corners

Why is the outside black or white?
Because you downloaded as JPG. JPG has no transparency, so the area outside the corners is filled with a background colour. Download as PNG instead.
My circular avatar came out as an oval?
That means the source is not square. Use the Resize tool to crop it to 1:1 first, then apply the circle crop.
How do I choose the radius?
Card images typically use 8–16 px; avatars just use the circle option; for a soft large radius try 10%–20% of the side length.
Can I round only two corners?
This version offers uniform corners on all four corners, plus the circle. To control individual corners, pre-process with another tool.
