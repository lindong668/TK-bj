How to read a QR code

  1. Save the QR code as an image (screenshot or long-press to save)
  2. Upload it here and recognition starts automatically
  3. The decoded content appears below and can be copied in one tap
  4. If it is a URL, click "Open in new tab" to visit it

How it works

Reading reverses the generation: locate the three corner finder patterns to fix position and angle, apply perspective correction to square up a skewed code, then read black and white values module by module.

The bit stream is unmasked first (using the mask number recorded in the format information), then verified and corrected with Reed-Solomon — which is exactly why slight damage is tolerated.

This tool prefers the browser's native BarcodeDetector API (supported in Chrome and Edge), running entirely locally with the best speed and no network needed.

If your browser lacks that API, jsQR loads from a public CDN as a fallback. That step needs the network, but the image itself is still processed only locally.

FAQ about QR reading

Why will it not decode?

Most often the image is too blurry or the code occupies too little of it. Upload a clean original and avoid recompression. Heavy skew, glare or obstruction also interfere.

Will my image be exposed?

No. The native path is fully offline; the network is used only to load a fallback library when unsupported, and the image always stays local.

Can it read several codes?

With the native BarcodeDetector, yes — it returns every code in the image. The jsQR fallback returns one at a time.

Can it read barcodes?

This version handles QR codes only. One-dimensional barcodes are planned for a later release.

Does it work in Safari or Firefox?

Yes. Neither supports the native API, so it falls back to jsQR automatically — same features, just a one-time download of the library.
