How it works

Formats differ essentially in how they compress and what they support. PNG is lossless, keeping every pixel and supporting an alpha channel. JPG is lossy, discarding high-frequency detail the eye barely notices to cut size sharply, but has no transparency. WebP is newer and supports lossy, lossless and transparency, usually producing noticeably smaller files than JPG at the same quality.

Under the hood the browser decodes the image into a pixel array on a canvas, then re-encodes it following the target format's rules. In other words, every conversion involves one decode plus one re-encode.

One trap worth knowing: converting JPG to PNG does not improve quality. The detail JPG discarded is gone for good; PNG just wraps those already-degraded pixels in a lossless container, and the file grows. The reverse, PNG to JPG, genuinely reduces size but drops the alpha channel.

Specifications

PNGLossless, supports transparency, larger files — good for screenshots and assets
JPG / JPEGLossy, no transparency, small files — good for photos
WebPLossy or lossless, supports transparency, smallest files — works in all modern browsers
BMPBarely compressed, very large — only for special cases
GIFUp to 256 colours, supports animation and simple transparency — not for photos

Conversion always means re-encoding. Saving back and forth between lossy formats keeps accumulating damage — use PNG for intermediate steps.

FAQ about format conversion

Why does a transparent image turn black or white as JPG?
JPG has no alpha channel, so transparent pixels must be filled with some colour. This tool fills them with the background colour, which is why you see white or black. Choose PNG or WebP to keep transparency.
Does JPG to PNG make an image sharper?
No. JPG damage is irreversible — PNG only changes the container and makes the file bigger. The only way to gain sharpness is to find a higher-quality original.
Should I choose JPG or WebP?
For the web, WebP is usually smaller at the same quality, so prefer it. If you are sending the file to someone or need maximum compatibility, JPG is the safer pick.
Does conversion reduce quality?
Converting to a lossy format (JPG, lossy WebP) does lose quality, and the loss accumulates with each save. Converting to a lossless format (PNG, lossless WebP) adds no new loss. Save intermediate results losslessly when editing repeatedly.
