How to use this tool

  1. Upload image A in the main upload area.
  2. Upload image B in the second box.
  3. Drag the slider to reveal A on the left and B on the right; tick "highlight differences" for a pixel diff map.
  4. Download the comparison canvas as a PNG.

Note: All processing happens in your browser: images are never uploaded. Download the comparison before closing the page.

How it works

Both images are drawn to off-screen canvases on a shared coordinate system. The slider simply clips the draw calls at a chosen x position; the difference mode subtracts RGB values pixel by pixel and marks any channel sum above the threshold.

When the two images have different dimensions, B can be stretched to A's canvas so the comparison stays aligned. Everything is computed in your browser.

Frequently asked questions

What if the two images are different sizes?
Keep "stretch B" ticked to align them to A's canvas, or untick it to draw B at native size from the top-left.
Why does the difference map show noise?
JPEG compression and slight re-encoding shift pixel values. Lower your expectations for lossy sources; PNG gives a clean diff.
Can I compare a HEIC photo?
Yes. HEIC/HEIF is decoded locally in a Web Worker when the browser cannot read it natively.
Are images uploaded?
No. Both images stay in your browser and are drawn to local canvases.

The comparison canvas is sized to the first image

Everything in this tool is drawn into a canvas whose width and height come from image A. Image B is then drawn into that same box, stretched to fill it. When the two files have identical dimensions — the normal case for a before/after pair — this is exact. When they do not, B is distorted, and the comparison shows a shape difference that has nothing to do with the content. The fit option avoids the distortion by drawing B at its native size inside the same box instead of stretching it.

This single detail explains most "the slider makes my image jump" reports. It is not a rendering bug; it is two different aspect ratios sharing one canvas.

What the slider position means

The slider is a percentage, not a pixel value. At 50 the canvas is cut at half its width and image A is drawn on the left of the cut while B shows on the right. Because the cut is calculated from the canvas width, the same percentage lands in a different place on a 1200 px image and a 4000 px image — which is correct, since the comparison is about content position rather than absolute pixels.

Difference mode shows compression, not just edits

Difference highlighting compares pixel values and marks where they disagree. There is no threshold control, so the output is honest to the point of being noisy: re-encoding the same photo as JPEG at a different quality changes almost every pixel slightly, and difference mode will light up the entire frame. A few dozen isolated specks usually mean "the same image, saved twice"; a solid shape means "something was actually changed here".

Read the pattern before the quantity. Large uniform regions of difference point at a colour shift or a re-crop; thin outlines around text point at sharpening or compression; a single rectangular patch points at a pasted element.

Why two identical files can look different

  • Colour profiles. One file may carry an embedded profile and the other may not, so the browser maps the same numbers through different transforms.
  • Alpha. A transparent PNG is composited over the page background; a JPEG of the same artwork already has a background baked in.
  • Scaling. If one image is displayed at a different size, the browser resamples it and softens detail before you ever compare pixels.

To compare fairly, load two files with the same dimensions, the same format and the same alpha handling. Comparing a PNG against a JPEG answers "what did the JPEG conversion change", which is useful, but it is not a like-for-like comparison.

Where this is genuinely useful

  • Checking that a compression pass kept the details you care about, by sliding across faces, text and edges.
  • Confirming that a watermark was applied where you expected and at the opacity you chose.
  • Verifying that two exports of the same logo differ only in the areas you edited.
  • Reviewing a retouch against the original without opening a desktop editor.

Boundaries

The tool reports no similarity score, no PSNR and no perceptual metric. It is a visual comparator: it helps you see, and leaves the judgement to you. It also does not align images, so a one-pixel offset between two captures will read as a large difference along every edge.
