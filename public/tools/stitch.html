How to merge images

  1. Click the upload area to select several images at once (hold Ctrl to multi-select)
  2. Use ↑ ↓ under each thumbnail to reorder, ✕ to remove
  3. Choose a direction: vertical for long images, horizontal for comparisons, grid for posters
  4. Set spacing, background colour and alignment, then click "Merge"

How it works

Merging first computes the canvas size: horizontal uses the sum of widths plus spacing with the tallest height; vertical is the reverse; grid takes the maximum width and height per row and column.

Each image is then drawn at its coordinates using your chosen alignment. When ratios differ, the shorter image is padded with your background colour.

Everything is drawn onto a new canvas; originals are never modified. The theoretical size limit comes from the browser, typically around 16000 px.

FAQ about merging

How many images can I merge?

There is no hard limit, but total pixels must stay under the browser canvas ceiling (roughly 16000×16000). A few dozen ordinary photos are usually fine.

What if the images differ in size?

Gaps are filled with the background colour. To unify them, crop every image to the same ratio with the Crop tool first.

Can I compress the merged result?

Yes. Compress the result afterwards, or shrink each source image before merging.

Can it sort them automatically?

Images follow the order you selected them; use the ↑ ↓ buttons to adjust. Filename sorting is planned for a later version.
