DPI and PPI

Print dot density versus image pixel density — and why pixels are what matter.

Print dot density versus image pixel density — and why pixels are what matter.

DPI (dots per inch) describes how many ink dots a printer places in an inch. PPI (pixels per inch) describes how many image pixels sit in an inch. A 3000×2000 file tagged 72 DPI and the same file tagged 300 DPI contain exactly the same pixels; only the physical print size changes — about 105.8 cm wide at 72 DPI versus 25.4 cm at 300 DPI.

You meet this when a print shop asks for “300 DPI”, a form asks for “295×413 px”, or an image jumps in size inside Word. To check whether a file is enough, multiply the target print size in inches by the target PPI: a 6-inch print at 300 PPI needs 1800 px of width.

On this site, Resize Image changes pixels, Rotate & Flip and crop cut to pixel sizes, and Images to PDF lays pages out at A4. None of them invents detail.

Common misconception: raising the DPI number from 72 to 300 does not sharpen anything; it only makes the image smaller in layout software.
