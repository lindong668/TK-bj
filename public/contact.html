This is our only official contact channel. Whether a tool broke, a result disappointed you, you have a feature idea or a privacy question, this inbox is the place.

What to include in your message

So we can locate and fix problems quickly, please include: the tool name, your browser and version (for example Chrome 130 or Safari 17), your device type (computer or phone), and exactly what happened.

Attaching the original image helps a lot if you can. Note that email passes through your provider, so if the image is sensitive, just describe the problem — we will never insist on the file.

Before you write: three checks

Most messages we receive describe one of three problems, and each has a quick check that saves a round trip.

  1. The page looks empty or a button does nothing. Open the browser console and look for an error, then try the page with extensions disabled. All editors need JavaScript; with scripting off, the page shows a notice and the controls stay inert by design.
  2. The result is blank, black or cut off. Check the pixel size of the source. Editors cap the working canvas at 3000 px on the long side, and stitching can exceed the browser's maximum canvas height. A very large file can fail before any control is touched.
  3. A download is missing or only the first of several arrived. Browsers throttle rapid consecutive downloads. If a prompt asks whether to allow multiple downloads, allow it; otherwise the remaining slices are blocked.

What we can and cannot help with

We can explain how a result was produced, confirm whether a behaviour is intended, investigate a reproducible bug and correct a page that describes a tool inaccurately. Because processing happens in your browser, we cannot see your file, cannot reproduce a problem from a description alone without a specimen, and cannot recover work that was already downloaded and overwritten.

We also cannot process an image on your behalf. There is no upload channel and no back office that can run a job for you; the guides exist precisely so that the workflow can be repeated without support.

Advertising, cookies and data requests

Questions about Google AdSense, the consent message or cookies are answered in the Reference Privacy Policy, including how to withdraw consent and how to control personalised advertising through Google's own settings. If something there is unclear, write to the address above and say which section is ambiguous.

A data request should name the page you visited and the approximate date. In most cases there is no stored record to return, because the site keeps no account, no upload and no history — but we will confirm that in writing rather than assume it.

Response time

We check email on business days and usually reply within 3 to 7 working days. Bug reports that include a browser version and a reproduction step are handled first; messages that only say "it does not work" take longer because the first reply has to ask for the missing detail.

Privacy requests

If you would like to access, correct or delete data related to you, mention it in your email. Note that because all processing is local we do not store your images and do not ask for personal information, so there is usually no user data to look up.
