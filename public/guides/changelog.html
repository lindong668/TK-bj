Why a changelog is part of the content, not paperwork

A site that never records what it changed gives a reader no reason to come back and no way to trust a dated result. Every report in Lab Notes states the date it was measured, the specimen file it used, and the tool it was measured on. When a browser update changes how an icon is chosen, or an encoder changes which metadata fields survive a save, the affected report is re-run and the date here moves. That is the whole maintenance policy.

How we avoid duplicate content

The ten existing guides cover fundamentals: formats, compression targets, size standards, transparency basics, DPI, EXIF risks, Base64, redaction, QR correction and watermarking. Lab Notes does not restate any of them. Each new report is built around a specimen, a measured table, or a reproducible experiment, and each links to the existing guide only when a definition is genuinely needed. Where two reports touch the same subject — EXIF in the privacy guide versus EXIF across a save chain in the metadata trail — the difference in question is stated explicitly in both pages.

Frequently asked questions

How often is this changelog updated?

Whenever a report is re-run, a tool formula changes, or a new failure mode is added to the QA sheet. The maintenance rhythm table above lists the triggers and where each result is recorded.

Are the reports translated into Chinese?

The ten original guides have Chinese versions under /zh/guides/. Lab Notes is currently English only; each new page declares its own language explicitly rather than pointing at a translation that does not exist.

Can I reuse the specimen files?

Yes. They are synthetic, contain no personal data, and are published so every measurement in the reports can be reproduced. The Downloads section of each report links to the exact files it used.

What happens if a browser changes its icon behaviour?

The affected field test is re-run with the same specimen, the date on that report moves, and a dated entry is added here. The method is published so you can re-run it on your own stack.

Does the site run any of this on a server?

No. The tools process images in the browser, and the reports describe what those local tools do. Files are never uploaded by the tools or by the guides.
