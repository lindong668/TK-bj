Privacy evidence, not a promise

PicCalc processes images in the browser tab. This page gives you a test you can repeat in about a minute, plus the limits of the claim so you know exactly what is and is not covered.

What “local” means here

When you choose a file, the browser reads it with the File API and decodes it into an image bitmap or a canvas inside the page. Every edit — resizing, colour changes, cropping, format conversion, EXIF stripping — is arithmetic on those pixels. Saving calls canvas.toBlob() and hands you a temporary blob: URL. There is no upload endpoint in the tool code.

Test it in 60 seconds

  1. Open any tool, for example Compress Image.
  2. Open DevTools (F12) → Network → clear the list.
  3. Upload a large photo and apply a setting. Watch the list while the preview updates.
  4. Filter by Fetch/XHR. You will see page assets, but no request whose body is your photo.
  5. Optional harder test: after the page loads, switch DevTools to Offline and edit again. The tool still works, because nothing needs the network.

If you want to check the code itself, the tool scripts are public files such as /assets/js/lab.js and the per-tool scripts. Search them for fetch(, XMLHttpRequest or sendBeacon: image data is not passed to any of them.

What is not stored

There is no account, no gallery and no server-side copy. The decoded image lives in the tab's memory and disappears when you close or reload the page. Downloads are generated locally as blobs.

Limits you should know

  • Hosting logs still exist. The page request itself reaches the CDN, as with any website. That log contains the URL, time and IP — not your image.
  • Your browser and extensions are outside our control. A screenshot extension or a synced clipboard can copy what you see.
  • Metadata removal is a separate step. Compressing an image does not necessarily remove EXIF; use EXIF Viewer & Cleaner when location data matters.
  • Very large files can exceed browser memory. Editing tools cap the working side at 3000 px; crop and upscale cap at 4000 px.
