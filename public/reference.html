Reference

Four ways to check the work instead of trusting a claim: real before/after examples, a use-case index that starts from what you want to do, a bilingual glossary, and a privacy test you can repeat in your own browser.
Before / after examplesOne measured example per tool: input file, settings, output size and the real screenshot. Start from your taskFavicon, HEIC to WeChat, long screenshot slicing, scans to PDF — the tool order and the traps. Image glossaryDPI, EXIF, ICC, alpha, bit depth, lossy, gamut, vector, canvas limits and export formats. Privacy evidenceWatch the Network panel while you edit: no request carries your image.

What each section answers

  • Examples: what exactly went in, what settings were used, and what came out.
  • Use cases: which tools to use, in what order, and where people usually go wrong.
  • Glossary: the terms that decide whether a file will print correctly or look wrong on another screen.
  • Privacy proof: a repeatable check, not a promise.
