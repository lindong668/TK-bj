Canvas 导出格式

PNG、JPEG、WebP 是原生格式；ICO、PDF、SVG 都要另外封装。

PNG、JPEG、WebP 是原生格式；ICO、PDF、SVG 都要另外封装。

canvas.toDataURL() 与 toBlob() 支持 image/png、image/jpeg、image/webp。JPEG 不支持透明，透明区会被填充；WebP 在旧 Safari 上可能退回 PNG。ICO、PDF、SVG 不是 canvas 原生格式。

导出后文件异常变大、透明变黑、扩展名与真实编码不符、把 data URL 直接粘进 CSS 导致体积暴涨，都是导出格式选错。

本站编辑类工具默认导出 PNG；格式转换提供 JPG/WebP/ICO；图片转 PDF 用 PDF 库重新封装；Base64 工具生成的是 PNG 的 data URL。扩展名与编码始终一致。

常见误解：把 .png 改成 .jpg 就完成转换。字节没变，上传系统仍会拒绝。
