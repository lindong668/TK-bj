如何使用这个工具

  1. 上传图片：手机照片、扫描件、截图都可以。
  2. 用快捷按钮做 90° / 180° 旋转或水平 / 垂直镜像，可叠加使用。
  3. 用任意角度滑块微调（-180° ~ 180°），并选择旋转后空白角的填充色。
  4. 应用并下载 PNG，透明角依然是透明的。

提示：所有处理都在浏览器内完成，图片不会上传。请在关闭页面前下载结果。

它的原理是什么

90° 旋转只是把像素搬到新坐标，完全无损。任意角度旋转会重新采样：画布先扩到旋转后的外接矩形，再通过旋转变换绘制，新的空白角用你选的颜色填充。

镜像本质是某一轴上的负缩放。两种操作都在离屏 canvas 上用高质量平滑完成，导出为 PNG 以保留透明通道。

常见使用场景

扶正扫描件轻微歪斜的文档，转 1~3° 后阅读体验立刻改善。
自拍镜像消除前置摄像头的镜像，让背景里的文字恢复正常。
商品图排版把横版商品图转成竖版画布，适配商品列表。

常见问题

90° 旋转会损失画质吗？
90° 和 180° 是无损的：不做插值，只是把像素换位置。其它角度会重新采样。
为什么旋转后边角是空的？
矩形旋转后不再填满水平的外接框。可以选填充色，或保持透明并导出 PNG。
JPG 旋转后能保留透明吗？
JPG 本身没有 alpha 通道。需要透明角就下载 PNG（本工具默认就是 PNG）。
照片会上传吗？
不会。旋转与镜像都是浏览器内的 Canvas 运算，文件从不离开设备。
