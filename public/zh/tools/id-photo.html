如何使用这个工具

  1. 上传图片：手机照片、扫描件、截图都可以。
  2. 用快捷按钮做 90° / 180° 旋转或水平 / 垂直镜像，可叠加使用。
  3. 用任意角度滑块微调（-180° ~ 180°），并选择旋转后空白角的填充色。
  4. 应用并下载 PNG，透明角依然是透明的。

提示：所有处理都在浏览器内完成，图片不会上传。请在关闭页面前下载结果。

它的原理是什么

90° 旋转只是把像素搬到新坐标，完全无损。任意角度旋转会重新采样：画布先扩到旋转后的外接矩形，再通过旋转变换绘制，新的空白角用你选的颜色填充。

镜像本质是某一轴上的负缩放。两种操作都在离屏 canvas 上用高质量平滑完成，导出为 PNG 以保留透明通道。

常见使用场景

扶正扫描件轻微歪斜的文档，转 1~3° 后阅读体验立刻改善。
自拍镜像消除前置摄像头的镜像，让背景里的文字恢复正常。
商品图排版把横版商品图转成竖版画布，适配商品列表。

常见问题

90° 旋转会损失画质吗？
90° 和 180° 是无损的：不做插值，只是把像素换位置。其它角度会重新采样。
为什么旋转后边角是空的？
矩形旋转后不再填满水平的外接框。可以选填充色，或保持透明并导出 PNG。
JPG 旋转后能保留透明吗？
JPG 本身没有 alpha 通道。需要透明角就下载 PNG（本工具默认就是 PNG）。
照片会上传吗？
不会。旋转与镜像都是浏览器内的 Canvas 运算，文件从不离开设备。

任意角度旋转后，四个角去哪了

把矩形转 15°，原图的四个角会转到画布外面，同时画布四角空出三角形区域。这页提供四种填充：透明、白色、黑色、自定义颜色。填充只作用于空白角，不会盖住原图内容。

透明导出的 PNG 可以直接叠到别的背景上；白色适合打印和文档，也最接近扫描件的底色；黑色适合深色海报；自定义颜色用来匹配页面底色，避免出现一圈突兀的白角。

90° 快捷操作与任意角度的分工

90°、180° 和水平/垂直镜像走快捷按钮，结果边界整齐、没有空白角，适合纠正手机拍摄方向、翻拍稿和倒置的扫描件。任意角度滑块范围 −180° 到 180°，会产生空白角，适合把拍歪的文档摆正。

两者可以叠加：先点 90° 把方向摆对，再用滑块微调 1–3°，比直接从原图拉一个大角度更容易控制。

镜像不改变画质

水平镜像左右翻转，垂直镜像上下翻转，像素值本身没有重采样，所以画质不会有任何损失。自拍矫正、检查设计稿对称性、翻拍文字时常用。注意镜像后的文字是反的，需要保持可读就不要用。

3000 像素的工作画布

旋转在长边不超过 3000 像素的工作画布上完成。更大的原图会先等比缩小；旋转后画布可能略微增大，但仍在同一量级。需要原始分辨率，请用本地软件处理。

输出与格式

默认导出 PNG，透明角才保得住。JPG 没有 alpha 通道，想要透明就得选 PNG；选白色或自定义色填充时，导出 JPG 再交给「格式转换」也可以。输入支持 HEIC/HEIF，仅作为来源，本站不导出 HEIC。

这一页不是证件照制作

页面地址里带着 id-photo，但实际功能是旋转与镜像，不提供换底、排版和证件照尺寸模板。需要一寸、二寸等规格，请先用「裁剪」按标准像素裁好，再用这一页把画面摆正。
