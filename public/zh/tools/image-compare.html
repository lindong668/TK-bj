如何使用这个工具

  1. 在主上传区放图片 A。
  2. 在第二个框放图片 B。
  3. 拖动滑块，左侧显示 A、右侧显示 B；勾选「差异高亮」看逐像素差异图。
  4. 把对比画布下载为 PNG。

提示：所有处理都在浏览器内完成，图片不会上传。请在关闭页面前下载对比图。

它的原理是什么

两张图先画到统一坐标系的离屏 canvas 上。滑块模式只是把绘制按选定 x 位置裁剪；差异模式逐像素相减 RGB，超过阈值的标成高亮色。

两图尺寸不同时，可把 B 拉伸到 A 的画布以保持对齐。所有计算都在浏览器内完成。

常见使用场景

修图前后一眼看出修图、滤镜或压缩前后的差别。
界面回归快速定位两个版本间变化的按钮或布局。
扫描件查重比对两版扫描件，看有没有增删内容。

常见问题

两张图尺寸不一样怎么办？
保持「拉伸 B」勾选即可对齐到 A 的画布；取消勾选则按原始尺寸从左上角绘制。
差异图为什么有噪点？
JPEG 压缩和二次编码会让像素值轻微偏移，有损图源会有噪点；用 PNG 做差异最干净。
能对比 HEIC 照片吗？
可以。浏览器原生读不了时，HEIC/HEIF 会在 Web Worker 里本地解码。
图片会上传吗？
不会。两张图都留在浏览器里，只绘制到本地 canvas。

画布尺寸永远取 A

对比画布按第一张图（A）的宽高建立，A 不会被缩放，它是对比的基准。B 与 A 尺寸不同时，默认把 B 拉伸铺满 A 的画布；取消「尺寸不同时把 B 拉伸到 A 的画布」后，B 按原始比例绘制，多出的部分留空。

这条规则决定了一个常见结果：A 的尺寸小、B 的尺寸大时，B 会被压小，细节可能被抹掉。想公平比较细节，先把两张图裁成同一尺寸。

差异高亮只算一次

拖动滑块只是移动遮罩，不重新计算，所以很顺。勾选差异高亮或点「对比 / 刷新」时才做一次逐像素比较，把不同的位置标出来。这也是为什么拖滑块流畅、切到差异模式会顿一下——它在遍历整张画布。

改动图片后要重新勾选或刷新，高亮不会自动跟着变。

它不给相似度分数

这页不计算 PSNR、SSIM 之类的指标，也不判断「哪张更好」。它只把两张图叠在一起让你用眼睛看。需要客观数值，请用专门的图像质量工具；需要看文字有没有改错，人眼仍然是最可靠的。

尺寸不一致的三种处理

最稳妥的是先把两张图裁成同一尺寸再对比；其次是让 B 拉伸，适合看整体构图差异；最后是取消拉伸，适合看局部内容是否被裁掉。拉伸会让 B 变形，判断文字和线条时不要用它。

输出

当前画布可以导出为 PNG，尺寸等于 A。透明区域保留，滑块线条和标签会一并画进去，用作说明图正合适；需要干净的成品图，请分别导出两张原图。

适合与不适合的场景

适合：修图前后对比、压缩前后细节检查、两个版本的设计稿核对、截图里的文字改动确认。不适合：色彩管理（浏览器会统一到 sRGB，广色域差异看不出来）、动画逐帧对比、超过画布上限的超大图。
